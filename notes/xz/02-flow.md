# 흐름: 12바이트 스트림 헤더/푸터 읽기 -> 검증 -> 옵션 구조체

주소는 `xz.exe` 가상 주소(이미지 베이스 0x140000000).

## X1~X3: 스트림 헤더 읽기, 함수 0x140014470 (result/fn-140014470.txt)
- 호출 형태: `rcx` = 결과 옵션 구조체, `rdx` = 입력 12바이트.
- 관측: 매직 포인터 `[0x14003e260]`를 읽어 4바이트(`mov edx,[rax]; cmp [rbx],edx`, 0x140014476~0x140014485)와 2바이트(`movzx eax,WORD PTR [rax+4]; cmp [rbx+4],ax`, 0x140014498~0x14001449c)를 입력과 비교. 불일치하면 `mov eax,0x7`로 반환(0x140014489). -> 결과: 처음 6바이트가 `fd 37 7a 58 5a 00`가 아니면 코드 7 반환(형식 오류로 추정).
- 관측: `call 0x140017110`(edx=2 길이, r8=0 초기값)에 `rbx+6` 전달(0x1400144a2~0x1400144ae), 반환값을 `[rbx+8]`의 4바이트와 비교(0x1400144ba), 불일치면 코드 9(`mov eax,0x9`, 0x1400144b5). -> 결과: 바이트 6~7(스트림 플래그 2바이트)의 체크섬이 바이트 8~11과 같아야 함. 체크섬 함수는 CRC32로 추정(호출 횟수 다수, 인자 (버퍼, 길이, 초기값)).
- 관측: `cmp BYTE PTR [rbx+6],0` 아니면(0x1400144bf), `cmp BYTE PTR [rbx+7],0xf; ja`(0x1400144c5) -> 코드 8(`mov eax,0x8`, 0x1400144f0). -> 결과: 플래그 첫 바이트는 0이어야 하고 둘째 바이트(체크 종류)는 0xf 이하.
- 관측: 성공 시 옵션 구조체 `[rsi]=0`, `[rsi+8]=0xffffffffffffffff`, `[rsi+0x10]=[rbx+7]&0xf`, 반환 0 (0x1400144cb~0x1400144e3). -> 결과: 버전 0, 백워드 사이즈 미정(-1), 체크 종류.

## X4: 스트림 푸터 읽기, 함수 0x140014500 (result/fn-140014500.txt)
- 관측: 반환값 기본 7(`mov eax,0x7`, 0x140014506). 매직 포인터 `[0x14003e240]`의 2바이트를 입력 `[rbx+0xa]`와 비교(`movzx ecx,WORD PTR [rbx+0xa]; cmp [rdx],cx`, 0x140014518~0x14001451c), 불일치면 7 반환. -> 결과: 입력 12바이트의 10~11번째가 `59 5a`("YZ").
- 관측: 체크섬 함수 호출(길이 6, 입력 `rbx+4`, 0x140014521~0x14001452d)과 `cmp edx,[rbx]`(0x140014539), 불일치면 9. -> 결과: 바이트 4~9(백워드 사이즈 4 + 플래그 2)의 체크섬이 바이트 0~3과 같아야 함.
- 관측: `[rbx+8]==0`(0x14001453d), `[rbx+9]<=0xf`(0x140014543), 아니면 코드 8(0x140014578). 성공 시 `[rsi]=0`, `[rsi+0x10]=[rbx+9]&0xf`, `[rsi+8]=([rbx+4] 4바이트)*4+4`(`lea rax,[rax*4+4]`, 0x14001455c), 반환 0. -> 결과: 백워드 사이즈 필드는 (값+1)*4바이트.

## X5: 상위 호출부, 함수 0x1400132c0 (파일 끝에서 거꾸로 읽는 디코더로 추정)
- 관측: 푸터 읽기 호출(0x1400133ed) 결과가 7이면 0x140013870로, 그 외 비0이면 0x1400136f5로 분기(0x1400133f5~0x140013400). 성공하면 백워드 사이즈 `[rbp+0x120]`에 12를 더한 값이 남은 길이 `[rbp+0x10]`보다 크면 오류 분기(0x14001340d~0x140013418), 아니면 상태를 4로 설정하고 길이를 줄임(0x140013425~0x140013436).
- 관측: 헤더 읽기 호출(0x1400135f8) 성공 후 `[rbp+0x18]`(파일 크기 필드로 추정)이 음수이거나(`js`) 하위 2비트가 0이 아니면(`test al,3`) 오류 분기(0x140013608~0x140013617) -> 결과(추정): 파일 크기는 4의 배수여야 함.
- 관측: 이어서 0x140013230 호출(인덱스 디코딩 준비로 추정), 인덱스 레코드 수와 블록 합계를 비교하는 코드는 이 세션에서 **찾지 못했다**(앵커 없음).
