# B-009 xz.exe 사전 등록

대상: xz 5.8.4 Windows 빌드 `xz-5.8.4-windows.zip`의 `bin_x86-64/xz.exe` (PE32+ x86-64).
다운로드 zip은 `targets/xz/xz-windows.zip`, 소스 tarball은 `analysis/xz/xz-5.8.4.tar.gz`(미개봉). 릴리스에 `.sig`가 있으나 서명 검증 도구·공개키가 없어 진위 **미확인**.

## 범위: `.xz` 파일 열기 중 스트림 헤더·스트림 푸터·인덱스 연결 검증 (디코딩 본체, 압축 알고리즘은 범위 밖)
단계 5개.

| 단계 | 내용 | 앵커 후보 |
|---|---|---|
| X1 | 스트림 헤더 매직(6바이트)과 스트림 플래그 읽기 | 바이트열 `FD 37 7A 58 5A 00`의 인라인 비교 상수(`cmp ...,0x58`/`0x5a`/`0xfd`)와 배열 참조(M-209: 읽기/쓰기 경로 구분) |
| X2 | 스트림 플래그 유효성(예약 비트, 체크 종류 범위) | 플래그 2바이트에 대한 비트 마스크(`and ...,0xf0`, 상위 바이트 0 확인), 체크 종류 값 비교 |
| X3 | 헤더 CRC32 검증 | CRC32 테이블 또는 CRC 함수 호출(호출 횟수 많은 함수), `cmp` 대상이 헤더의 +8 위치 4바이트 |
| X4 | 스트림 푸터 검증(CRC32, 백워드 사이즈, 플래그 일치, 매직 `YZ`) | 매직 `59 5A` 비교, 푸터 12바이트 크기 상수 `0xc`, 헤더 플래그와 푸터 플래그 비교 |
| X5 | 인덱스·블록 크기 연결 검증(인덱스 레코드 수와 블록 합계 일치) | 인덱스 디코더 호출 지점, 실패 시 오류 코드 매핑(`LZMA_DATA_ERROR` 등 정수 상수와 메시지 표) |

## 앵커 우선순위 (M-008 단계)
1. 고유 필드 오프셋·매직 상수(M-209: 읽기 경로 후보를 인라인 비교로 찾는다).
2. CRC 함수 호출 횟수·인자(`push 4/6/12` 길이 상수).
3. 오류 메시지 표(포인터 배열)와 정수 오류 코드 매핑.

## 채점 규칙(소스 열기 전 확정)
- B-008과 동일: 단계마다 분기·값·오류 조건을 항목으로 센다. 소스에 있고 노트에 없는 분기는 누락.
- M-008 유효 판정: 누락 2 이하 & 오답이 기준선(0~3) 이내. 누락 3~4 효과 불확실, 5 이상 효과 없음.
- 기준선: 네이티브 5건 누락 4~6.
