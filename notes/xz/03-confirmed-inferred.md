# 확인 / 추정 / 미확인 (소스 열기 전)

## 확인
1. 헤더 읽기: 처음 6바이트 매직 비교, 불일치 시 코드 7 (X1)
2. 헤더 읽기: 바이트 6~7의 체크섬을 바이트 8~11과 비교, 불일치 시 코드 9 (X3)
3. 헤더 읽기: `[6]==0`, `[7]<=0xf` 아니면 코드 8 (X2)
4. 헤더 성공 시 옵션 `[+0]=0`, `[+8]=-1`, `[+0x10]=[7]&0xf` (X2)
5. 푸터 읽기: 10~11번째가 `59 5a`, 불일치 시 코드 7 (X4)
6. 푸터 읽기: 바이트 4~9의 체크섬을 바이트 0~3과 비교, 불일치 시 코드 9 (X4)
7. 푸터 읽기: `[8]==0`, `[9]<=0xf` 아니면 코드 8, 성공 시 백워드 사이즈 = 필드*4+4 (X4)
8. 읽기 함수와 쓰기 함수 분리: 헤더 쓰기 0x140010cc0, 푸터 쓰기 0x140010d50 (M-209)
9. 상위 호출부가 푸터 결과 7과 그 외 비0을 다른 분기로 처리하고, 백워드 사이즈+12 > 남은 길이를 오류로 봄 (X5 일부)

## 추정
- 체크섬 = CRC32
- 코드 7, 8, 9 = 형식 오류, 옵션 오류, 데이터 오류
- 파일 크기가 4의 배수여야 함 (`test al,3`)
- `0x140017110`의 시그니처 (버퍼, 길이, 초기값)
- 0x1400132c0 = 파일 끝에서 푸터, 인덱스를 거꾸로 읽는 디코더

## 미확인
- 인덱스 레코드 수와 블록 합계 교차 검증 위치(X5)
- 헤더/푸터 플래그 일치 비교(함수 위치)
- 체크 종류 값 0xf 이하 중 실제 지원 종류(허용되는 값 목록)
- 오류 코드 매핑 표
