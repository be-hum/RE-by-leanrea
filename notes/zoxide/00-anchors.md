# B-008 zoxide 사전 등록

대상: zoxide v0.10.0 `zoxide-0.10.0-x86_64-unknown-linux-musl.tar.gz`의 `zoxide` (static-pie, stripped, Rust).
다운로드 sha256: tarball `2d93385b99f3e82cf2701609a1bffcad863fbeb75aa3fe7eb6be4d29be68b1ae`, 바이너리 `0959b169db9adac07187ab99b0d9806f616fbe7938cf84f9f4e2422d8de16e6c`. 릴리스 쪽 체크섬은 확인하지 않음.

## 범위: `zoxide add <path>` 경로 (실행하지 않고 정적으로)
단계 5개. 각 단계마다 "담당 함수 주소"를 노트 02에 적고, 못 찾으면 "미확인(앵커 없음)"으로 쓴다.

| 단계 | 내용 | 앵커 후보(바이너리에서 찾는 방법) |
|---|---|---|
| S1 | 데이터 디렉터리 결정(환경 변수, 기본 경로) | 환경 변수 이름 문자열(`_ZO_DATA_DIR`, `XDG_DATA_HOME`, `HOME`)과 그 참조 `lea`; 파일 이름 문자열 |
| S2 | DB 파일 읽기·역직렬화(버전 확인) | 패닉/오류 Location의 경로(`src/db/...`), 오류 문자열(버전, 손상), `read` 호출 주변 |
| S3 | 경로 추가 또는 순위·시각 갱신 | 시각(`SystemTime`/`clock_gettime`) 사용 함수, 순위 가산 상수, 경로 정규화 오류 문자열 |
| S4 | 총 점수 초과 시 노화(aging) | 환경 변수 `_ZO_MAXAGE` 문자열 참조, 부동소수점 비교·곱셈 상수, 점수 1 미만 삭제 비교 |
| S5 | DB 저장(임시 파일 쓰기 후 이름 변경) | `rename`/`sync` 호출, 임시 파일 이름 문자열, 권한 설정 |

## 앵커 우선순위 (M-008 단계)
1. 패닉 `Location`(경로 문자열을 가리키는 RELATIVE 재배치 -> `.data.rel.ro`의 (len, line, col)): 크레이트 경로 문자열 `src/db/`, `src/cmd/add.rs` 같은 것이 있으면 줄 번호로 함수를 잡는다.
2. 환경 변수 이름과 오류·로그 문자열의 `lea` 참조.
3. 공유 상수(부동소수점, 시간)와 호출 횟수·순서.

## 채점 규칙(소스 열기 전 확정)
- 항목 단위: 단계마다 "분기·값·오류 조건"을 항목으로 센다. 항목 목록은 노트 02·03의 확인/추정/미확인 문장 단위로 나누고, 소스 대조 시 소스에 있으나 노트에 없는 분기는 누락으로 센다.
- 판정: 맞음 / 추정 적중 / 누락 / 오답. "미확인"으로 적은 항목이 소스에 있으면 누락.
- M-008 유효 판정 기준: 누락 2 이하이고 오답이 기준선(0~3)을 넘지 않을 때. 누락 3~4는 효과 불확실, 5 이상은 효과 없음.
- 기준선: 네이티브 5건 누락 4~6, 오답 0~3 (B-001/007/002/003/004).
