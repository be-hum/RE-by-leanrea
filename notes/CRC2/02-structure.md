## 구조
- `FUN_00401680`: `IsWow64Process`로 WOW64(64비트 Windows) 확인 후 `FUN_00401490` 호출, 결과 문자열(0x410160, 기본 "Wrong") 출력.
- Heaven's gate: `push 0x33; call $+5; add [esp],5; retf`로 64비트 모드 진입, `mov [esp+4],0x23; add [esp],0xd; retf`로 복귀. 64비트 구간도 32비트 컴파일 코드라 의미는 동일(Ghidra는 0x401000/0x4012d0을 빈 함수로 오인).
- `FUN_00401000`: 0x40fec8의 0x120바이트(BMP 50x4 헤더+픽셀)에서 0이 아닌 바이트만 0x410f00으로 복사. CRC-64 테이블(0x411020) 생성, 반사형 poly `0x8c997d55124358a1`. XOR은 비트 배열 비교(`!a&p | a&!p`)로 구현.
- `FUN_004012d0`: 같은 방식의 64비트 XOR.
- `FUN_00401490` 검사:
  1. 입력 길이 13, 각 문자 `[0-9A-Za-z]`.
  2. i번째 문자를 0x410f00 + 20*i에 기록, 문자 합 == 0x4d0.
  3. 버퍼 256바이트 CRC-64(init 0, final xor 없음) == `0x81bad8907de045eb`이면 0x410160을 "Correct\n"로 덮어씀.
