# 확인 / 추정 / 미확인 (소스 열기 전)

## 확인
1. 한 줄 파싱 함수 0x1f5890: 빈 줄/`#` 건너뜀, `\!`와 `\#` 이스케이프 검사, `!` 플래그, 앞 `/` 소비, 끝 `/` 플래그와 앞 `\` 처리, `/` 유무 스캔, `**`와 `**/` 접두 검사
2. 글롭 집합 전략 분류 7종(리터럴, 기본이름, 확장자, 접두, 접미, 필수 확장자, 정규식) 디버그 문자열
3. 글롭 오류 종류 7종 문자열
4. 전역 무시 파일을 얻는 데 정규식 `excludesfile` 줄 파싱 사용, CWD를 모르면 건너뜀
5. 패닉 "Ignore::add_parents called on non-root matcher"가 0x10d550에 있음

## 추정
- 이스케이프 안 된 끝 공백 제거
- 앞 `/` = 루트 고정, 끝 `/` = 디렉터리 전용
- 슬래시 없는 패턴에 `**/`를 앞에 붙임, `**`로 시작하면 붙이지 않음
- `excludesfile`은 `core.excludesFile` 값
- `!` = 화이트리스트(부정)

## 미확인
- 규칙 파일 우선순위의 코드 구현(매뉴얼 문구만 확인)
- 마지막 규칙이 이기는지, 매칭 순서
- 디렉터리 전용 규칙을 파일에 적용하는 조건
- `/*`를 붙이는 조건
- 대소문자 무시, literal_separator, 백슬래시 이스케이프 플래그의 글롭 빌더 설정
- `.git` 디렉터리를 요구하는 조건(`--no-require-git` 플래그는 매뉴얼에 있음)
- 0x1f23a0이 하는 일
