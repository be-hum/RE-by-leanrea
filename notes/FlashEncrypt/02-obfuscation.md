## 난독화
- 버튼 액션은 상태 변수 `\x01`(초기값 316 + `\x04\x05()` 반환값) 기반 제어흐름 평탄화. 쓰레기 constpool, 스택 잔여값을 쓰는 불투명 분기 포함.
- 실제 로직은 각 버튼 태그 바로 앞의 비표준 태그 253에 있음. 버튼 코드가 음수 오프셋 점프(예: 0x4a0 `jump -0x4cf`)로 액션 블록 밖, 태그 253 데이터로 진입. 선형 디스어셈블로는 안 보임.
