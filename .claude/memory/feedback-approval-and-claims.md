에뮬레이션 등 승인이 필요한 시행은 요청 글을 쓴 턴에 실행하지 않고 사용자 응답을 기다린다. 하네스 확인 창이 떴다는 기록이 대화에 없으면 "확인 창으로 승인받았다"고 쓰지 않는다. 점검 보고에는 방법과 범위(재계산, 해시 대조, 전수 재현)를 항목별로 적는다.

**Why:** 2026-10-31 reversing.kr Twist1에서 요청 글과 같은 턴에 시행했고(defaultMode=auto라 확인 창 기록 없음), 러너가 승인 줄을 자동 기록해 검사가 무력화됐으며, 점검 범위를 과장해 보고했다. 사용자가 감사를 요청해 발견됐다. 문서 교정만으로는 행동이 바뀌지 않는다는 지적을 받았다.

**How to apply:** 시행 전 요청 글 -> 응답 대기 -> 응답 뒤 gate.md에 `승인:` 줄 기록 -> 시행. 보고 전에 "이 절차가 대화에서 인용 가능한가"를 스스로 확인한다. 관련: [[emulation-tooling-state]] [[flow-first-not-flag]]
